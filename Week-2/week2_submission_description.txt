This Week 2 report extends the Week 1 Car Evaluation project into advanced data visualization and storytelling using Python. The same UCI Car Evaluation dataset was retained to maintain continuity across the internship. The dataset contains 1,728 observations, six categorical input variables, and a four-class categorical target representing car acceptability. The objective of this week was not simply to create charts, but to organize visual evidence into a clear narrative that can be understood by a non-technical audience.

Five visualizations were developed using Python and Matplotlib. The first visualization presents the distribution of the four acceptability classes and establishes the main analytical issue: the unacceptable class is much larger than the other outcomes. The second visualization communicates the balanced structure of the input features using percentage-based category profiles. The third visualization uses Shannon entropy to compare categorical diversity across features. The fourth converts target counts into percentages to provide an intuitive stakeholder-level interpretation of the class imbalance. The fifth visualization compares feature cardinality and shows that some decision factors have four possible categories while others have three.

Each visualization is accompanied by an explanation of why that visual form was selected, what the audience should notice, and how the finding contributes to the overall story. The report also discusses business and scientific implications, including the importance of class-aware modelling and careful interpretation of categorical data. Limitations are documented to avoid overgeneralizing a structured benchmark dataset to the modern automobile market. The final section provides reproducible Python code so the visual analysis can be regenerated. Overall, the report demonstrates the progression from basic EDA to purposeful, audience-oriented data storytelling.
